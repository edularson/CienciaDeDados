# Ciência de Dados

Exercícios e trabalhos acadêmicos de Ciência de Dados desenvolvidos durante o curso de Ciência da Computação na UNICENTRO.

## Projeto em destaque

### Pipeline de dados públicos de saúde

O [projeto em Trabalho2](Trabalho2) coleta um CSV, trata os dados com pandas, calcula estatísticas, produz gráficos e armazena os registros em SQLite. A [documentação do pipeline](Trabalho2/README.md) explica a configuração, a execução e os arquivos gerados.

## Organização

- `Aula4`, `Aula6` e `Aula7`: exemplos e atividades de aula.
- `Exercicios`: atividades de manipulação de dados, arquivos, APIs e bancos de dados.
- `Trabalhos`: trabalhos de coleta e processamento de informações.
- `Trabalho2`: pipeline de análise de dados públicos de saúde.

As pastas são atividades independentes; consulte os arquivos de cada uma para identificar suas dependências e entradas.
